About this project

This interactive demonstration explores the shortest-path problem using a curated sample of film credits. It is inspired by the Degrees of Separation project in Harvard's CS50 AI coursework.

Dataset note: This version contains a limited, hand-curated sample—not the full CS50 database. Only actors and connections included in this sample can be searched. A path is shortest within this sample, not necessarily across all films.
